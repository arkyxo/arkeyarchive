# RK Portfolio

Vite + React + Tailwind. Every push to `main` is built and published to GitHub Pages automatically
(see `.github/workflows/deploy.yml`).

- `src/App.jsx`     your sections and data
- `src/styles.css`  custom CSS
- `src/assets/`     thumbnails, skill icons, resume PDFs
- `index.html`      page title, description, fonts

To change something: open the file on GitHub, click the pencil icon, edit, and commit.
Check the Actions tab: a green check means the site is live, a red cross means the build failed
(the live site keeps its last working version).

Local preview (optional): `npm install` then `npm run dev`.
